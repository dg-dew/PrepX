K-th Smallest Path Sum in Grid

Graph Heap Dijkstra

Given an m × n grid of non-negative integers, you may move from any cell to a 4-directionally adjacent cell. The cost of a path is the sum of values on it. Return the k-th smallest path sum starting at (0, 0) and ending at (m-1, n-1).

Constraints
  • 1 ≤ m, n ≤ 200
  • 0 ≤ grid[i][j] ≤ 104
  • 1 ≤ k ≤ 105
Example 1
Input: grid = [[1,3,1],[1,5,1],[4,2,1]], k = 2
Output: 8
// paths: 7 (min), 8 (2nd smallest), 9, 12, ...
Auto-save · 4s ago 
import heapq

def kthSmallestPath(grid, k):
    m, n = len(grid), len(grid[0])
    heap = [(grid[0][0], 0, 0)]
    seen = {(0, 0): 1}
    count = 0

    while heap:
        cost, r, c = heapq.heappop(heap)
        if (r, c) == (m - 1, n - 1):
            count += 1
            if count == k:
                return cost
        for dr, dc in ((1,0),(-1,0),(0,1),(0,-1)):
            nr, nc = r + dr, c + dc
            if 0 <= nr < m and 0 <= nc < n:
                heapq.heappush(heap, (cost + grid[nr][nc], nr, nc))
    return -1
